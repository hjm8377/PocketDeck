# Pocket Deck

Windows PC에서 버튼을 배치하고 연결한 기기의 브라우저에서 눌러 쓰는 스트림덱입니다.

## 설치와 연결

1. Pocket Deck이 열려 있다면 닫고, `PocketDeckSetup.exe`를 실행한 뒤 **설치**를 누릅니다. 설치 후 Windows 시작 메뉴에서 **Pocket Deck**을 열 수 있습니다.
2. PC 앱을 처음 열면 **기기 연결** 화면이 나옵니다. PC와 연결할 기기를 같은 공유기에 연결한 뒤, 기기의 브라우저에서 PC 앱에 표시된 주소를 `http://`부터 입력합니다. Windows 방화벽에서 묻는다면 집 공유기가 속한 개인 네트워크를 선택합니다.
3. 브라우저에 8자리 숫자 연결 코드를 입력하면 PC 앱이 버튼 설정 화면을 엽니다. 오른쪽 동작 목록에서 기능을 버튼 칸에 끌어놓고, 아래의 **버튼 설정**에서 선택한 버튼을 꾸밉니다. **기기에 적용**을 누르면 기기 화면에도 배치가 반영됩니다.

접속 주소, 연결 코드, PC 미리보기는 **설정 → 기기 연결**에서 확인할 수 있습니다. **설정 → Windows 시작 시 실행**을 체크하면 Windows에 로그인할 때 Pocket Deck이 열립니다.

PC에서 드래그하는 동안 반투명 버튼이 커서를 따라오고, 놓을 칸에 파란 테두리가 표시됩니다. 기본 배치는 3열 × 2행입니다. 행과 열 수, 버튼 이름, 아이콘, 색상, 동작을 바꿀 수 있습니다. 음악 및 볼륨 제어, Windows 프로그램(.exe) 실행, `Ctrl+Shift+M` 형식의 단축키를 지원합니다.

프로그램 실행 버튼은 선택한 `.exe`의 아이콘을 표시합니다. 버튼 설정의 아이콘 칸에 문자나 이모지를 입력하면 해당 아이콘이 적용됩니다.

오른쪽 **위젯**에서 시계, 날씨, 볼륨 믹서를 놓고, 아래의 **가로 × 세로 (칸)**에서 크기를 정합니다. 위젯을 늘리려면 오른쪽과 아래의 칸을 비워 두세요. 기존 동작을 비우려면 버튼 설정에서 **동작 없음**을 고릅니다. 시계는 연결한 기기의 시간을 표시합니다. 날씨는 입력한 도시 이름을 Open-Meteo에서 검색해 현재 기온과 날씨를 표시합니다. 볼륨 믹서에서는 Windows 기본 출력 장치의 전체 볼륨이나 오디오 세션이 있는 앱을 선택하고 슬라이더로 조절합니다.

기기 화면은 가로·세로 방향 모두 스크롤 없이 한 화면에 배치를 맞춥니다. 버튼은 누르고 있는 동안 어두워집니다.

## 내 디자인 수정

PC 앱 메뉴에서 **Pocket Deck → 기기 화면 디자인 폴더 열기**를 선택합니다. `phone.css`에서 배경, 글꼴, 버튼 간격과 모서리를 바꾸고 `index.html`에서 화면 구조를 수정할 수 있습니다. 저장한 뒤 연결한 기기에서 새로고침합니다.

배치, 디자인, 업데이트 저장소 설정은 `%LOCALAPPDATA%\Pocket Deck`에 저장됩니다. 업데이트와 Windows 설치 앱 목록을 통한 제거 후에도 이 폴더의 사용자 데이터가 유지됩니다. 기본 화면으로 되돌리려면 해당 디자인 파일을 다른 폴더로 옮긴 뒤 새로고침합니다.

## GitHub Releases 업데이트

앱은 시작할 때 설정된 공개 저장소의 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 메뉴에 **업데이트 있음**이 표시됩니다. 버전 설치를 선택하면 GitHub 릴리스에 있는 `PocketDeckSetup.exe`를 내려받아 파일 크기와 SHA-256을 확인하고, 앱을 닫아 설치한 뒤 다시 엽니다. 접속 주소가 같으면 기기의 브라우저가 저장한 연결 코드를 다시 사용합니다.

직접 빌드한 설치 파일이라면 **Pocket Deck → GitHub 업데이트 저장소**에서 `소유자/저장소`를 입력합니다. GitHub Actions에서 빌드하면 해당 저장소 이름이 설치 파일에 자동으로 포함됩니다. 앱의 업데이트 확인은 공개 Releases에 별도 GitHub 로그인 없이 접근합니다.

## 빌드 및 릴리스

- Windows에서 `Build.cmd`를 실행하면 `dist/PocketDeckSetup.exe`가 생성됩니다.
- 로컬 빌드에서 기본 업데이트 저장소를 지정하려면 PowerShell에서 `$env:POCKETDECK_REPOSITORY = 'owner/repo'`를 설정하고 `.\Build.cmd`를 실행합니다.
- 소스 패키지를 저장소 루트에 넣고 `BuildInfo.cs`의 버전을 올린 뒤, 일치하는 `v1.1.0` 형식의 태그를 푸시합니다. 포함된 GitHub Actions가 설치 파일을 빌드하고 같은 태그의 Releases에 게시합니다.
